# 🥭 Campo de mango – app de registro

App para registrar, desde el celular y aunque no haya señal, todo lo del campo: jornales, labores, fertilizantes e insumos, gastos, ventas y cobros. También muestra el clima del día.
Todo se guarda en **tu Google Sheets**.

- `docs/`: la app (GitHub Pages la publica desde esta carpeta)
- `apps-script/`: el puente con el Google Sheets y el clima automático
- `plantilla/`: el archivo base de la base de datos
- `INSTALACION.md`: pasos para dejarla funcionando
- `CLAUDE.md`: guía para que una IA haga cambios sin perder información
